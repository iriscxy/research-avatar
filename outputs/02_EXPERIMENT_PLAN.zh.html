可行性。单张 A100 80GB 足够：SafeMoE 就是在 1× A100 80GB 上、以 OLMoE-1B-7B 为主模型完成整个 MoE 防御研究的。我们把 OLMoE-1B-7B-0924-Instruct 作为主要目标，把 Qwen3-30B-A3B（SAFEx 的招牌模型，6144 个专家）作为迁移验证。全程 LoRA + 推理期攻击评测，无需多卡训练。安全性用现成的 Llama-Guard 分类器判定（与 SteerMoE/SafeMoE 一致）。

0 · 预期摘要  预期 — 非真实结果

混合专家语言模型经过对齐、会拒绝有害请求，但近期工作表明它们的拒答行为集中在少数几个安全关键专家上，于是只要禁用一小撮专家就能移除安全护栏。已有的防御要么在攻击之后才恢复拒答、要么需要原始的安全对齐路由权重，而一个已部署的模型并没有这些权重。我们提出 SafeSpread，一种把拒答行为摊分到许多专家上、使得没有任何一个可被消融的小子集独自承载它的方法。我们先从路由统计中定位安全关键专家，然后做一次轻量的 LoRA 微调，配一个路由正则项和一个反集中项，把与拒答相关的路由质量推到许多专家上，且只用已部署的模型。在标准的有害集和越狱集上，SafeSpread 把专家消融下的最坏情况拒答跌幅从 [X%] 降到 [X%]，即便攻击者针对加固后的模型重新优化消融，也能把跌幅压在 [X%] 以内。它的代价是 [X%] 的能力损失，且不带来可测的过度拒答。这些结果给出了一种可部署的、能消除对齐混合专家模型专家消融脆弱性的办法。

结构：背景（MoE 经对齐会拒答）→ 问题（拒答集中在少数专家、消融即可攻破、已有防御需参考权重）→ 方法（SafeSpread：定位 + 路由正则摊分，只用已部署模型）→ 结果（占位符）→ 结论。摘要↔claim 自检：集中 → C1；最坏跌幅下降 → C2；扛住自适应再攻击 → C3；不需参考权重 → C4；能力/过度拒答代价低 → C5。所有数字都是占位符。

Introduction — 每段一句主旨（共 4 段，gap-first，你的风格）

  1. P1（全景 → 缺口）：MoE 大模型经过对齐会拒绝有害请求，但稀疏模型里的安全性并没有均匀地分布在各专家上。
  2. P2（收紧缺口）：拒答集中在少数安全关键专家上，于是攻击者只要禁用一小撮专家（或把路由从它们那里引开）就能移除护栏，而现有防御要么攻击后才恢复拒答、要么需要原始对齐路由权重。
  3. P3（贡献）：我们提出 SafeSpread，在一次轻量 LoRA 微调里用路由正则项和反集中项把拒答摊分到许多专家上，只用已部署的模型，使得没有任何一个可被消融的小子集独自承载护栏。
  4. P4（贡献清单）：我们 (i) 在多个 MoE 家族上量化这种集中脆弱性；(ii) 提出 SafeSpread，一种无需参考权重的再分布防御；(iii) 在静态、自适应、仅输入三类攻击下评测它；(iv) 证明最坏情况拒答跌幅从 [X%] 降到 [X%]，能力代价 [X%]。

Discussion / Conclusion — 主旨句

2 · 系统 — 方法 + 必须击败的 baseline

方法：SafeSpread

  • 用 SAFEx 稳定性专家选择（SES）定位安全关键专家。
  • 用 LoRA 微调再分布：把与拒答相关的路由质量摊分到许多专家的路由正则 + 关键集合上的反集中熵项。
  • 正则化路由器，使其微调后不再把拒答重新集中。
  • 攻击评测：最坏情况 k-专家消融（静态 + 自适应）与仅输入路由越狱。

4 · Run 顺序  smoke → baseline → main → ablation → polish

  1. Smoke（W1，先做便宜/确定性的）：OLMoE-1B-7B、50 条有害 + 50 条良性——验证 SES 定位、消融攻击框架、Llama-Guard 判定能端到端跑通并产出一个拒答数字。
  2. Baseline / 审计：在未防御 OLMoE 上复现 SAFEx 集中度曲线（C1）；跑 SAFEx-修复与 SafeMoE 基线。
  3. Main：SafeSpread 微调 + 重新测最坏情况消融曲线（C2）。
  4. 自适应：攻击者在加固模型上重新优化消融 + 仅输入越狱（C3）。
  5. 消融：A1–A5，每个只改一个变量。
  6. Polish：迁移到 Qwen3-30B-A3B；3-seed 重复；能力 + 过度拒答表。
