§0 · 投影标题与摘要 PROJECTED

Routed Away: Concept-Direction Fragmentation and Routing-Aware Steering in Mixture-of-Experts

摘要(投影——这是 I2 若成功后论文会有的摘要;每个数字都是占位,不是结果)。

通过往残差流里加一个向量来 steer 一个概念,是控制语言模型的一种标准做法,但在 Mixture-of-Experts 模型里它的效果参差不齐、常常很弱,而且原因不清楚。我们证明成因是几何的。一个概念的 steering 方向并不是一根共享向量;它被拆散到表达该概念的那些专家上。我们把这叫作路由碎片化(routing fragmentation),并把它逐概念地量化为逐专家差向量的离散度。当碎片化很高时,稀疏路由会把一个 token 送到并不承载该概念的专家上,于是单个残差向量被"路由甩开",其效果下降 [X%]。我们提出 Route-Then-Steer:先给 router 加一个小偏置,让 token 到达表达它的专家,再施加概念向量。在高碎片化概念上,Route-Then-Steer 把 steering 成功率从 [X%] 提到 [X%]、把跨样本方差削减 [X%],同时在 refusal 这类低碎片化概念上与普通 steering 持平。这个增益能被碎片化预测,说明 MoE 里 steering 的失败是路由几何效应,而非向量太弱。我们放出碎片化度量与 Route-Then-Steer,面向 OLMoE 与 Qwen-MoE。

风格自检:gap-first 开头、命名机制(路由碎片化 / Route-Then-Steer)、"我们提出 / 我们放出"式陈述、无破折号、无生僻词、≤180 词。标题保留英文原名(投稿即用)。

摘要↔claim 自检:碎片化存在且可测 → C1;高碎片化时残差向量被路由甩开 → C2;Route-Then-Steer 恢复控制、打败基线 → C3;增益被碎片化预测、在 refusal 上持平 → C4。没有哪句摘要缺一个支撑实验。

§0.5 · 投影论文骨架 PROJECTED

结构参照最接近的一篇 Expert-Aware Refusal Steering(2606.04160)(Intro → Method:残差 vs expert-specific → 跨 MoE 模型的 Experiments → Discussion),并按 CRH 式 gap-first 方法论文调整(CRH 作理论模板)。§1–§6 就是填充 Experiments 那节的具体实验。

1 · Introduction(每段一句主题句)

  1. 钩子 / gap:steering 是最便宜的推理期控制旋钮,但 MoE 已是默认开源架构,而 steering 在那里表现飘忽。
  2. 谜题:已有工作说残差 steering "照常起效",但 expert-aware 变体反而更弱、且一个行为能被单个专家主导——这些凑不到一起。
  3. 我们的诊断:一个概念方向被拆散到表达它的各专家上;我们把它做成一个可测的几何量(离散度),把 CRH 从 dense 残差流延伸进稀疏路由。
  4. 后果:当碎片化高时,残差向量被路由甩开,而这恰是 steering 失败之处。
  5. 修复 + 贡献:Route-Then-Steer、一个碎片化度量,以及"增益被碎片化预测"(且在低碎片化 refusal 上持平)这一结果。

2 · Related Work(分节 + 一句定位)

  • Activation steering 及其几何 — CAA、LRH、CRH:把 CRH 的逐样本圆柱几何从 dense 搬进 MoE。
  • MoE 里的 steering 与控制 — Expert-Aware Refusal Steering、SteerMoE、MASCing:只做了 refusal,且没有"何时需要 routing-aware"的几何预测器。
  • Router 干预 — Rewiring Experts:提供"route"这一步复用的免数据 router-logit nudge 原语。
  • 专家专业化之争 — Myth of Expert Specialization vs Domain Experts Exist:碎片化给这个隐状态几何问题一个概念级、因果的抓手。

3 · Method(按模块命名的小节)

  • 3.1 逐专家概念方向。强制路由到每个专家(router-logit offset,参 Expert-Aware Refusal Steering),在该专家 FFN 输出上算 difference-in-means 向量。
  • 3.2 碎片化度量。逐专家方向集合的离散度(平均两两 1−cosine,或 1 − 顶层共享方向解释的方差)。每概念一个数。
  • 3.3 routed-away 检验。因果核验:比较残差 steer 在"强制把 token 送到表达专家"与否两种情况下的效果。
  • 3.4 Route-Then-Steer。给 router logit 加偏置 δ(Rewiring 式)推向 top 表达专家,再施加残差概念向量;强度 λ 与 nudge α 在 §5 设定。

5 · Discussion / Conclusion(各一句主题句)

  • Discussion:碎片化调和了领域内的矛盾——残差 steering 在低碎片化概念(如 refusal)上"有效"、在高碎片化概念上失败,所以 routing-aware 必须是有条件的,而非默认。
  • Conclusion:MoE 里的 steering 可靠性是一个路由几何问题,而且有一个便宜、可预测、推理期的修复。
