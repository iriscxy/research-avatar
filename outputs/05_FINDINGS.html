Findings — I1 · SafeSpread (Safety-Redundant MoE)

Plan: 02_EXPERIMENT_PLAN.html · Tracker: 04_EXPERIMENT_TRACKER.html · Primary OLMoE-1B-7B, transfer Qwen3-30B-A3B. Every number here traces to a results/ file (synthetic).

Headline

On OLMoE-1B-7B, SafeSpread cuts the worst-case refusal drop under 8-expert ablation from 21.4% (undefended) to 4.6%, beating the closest defenses (SAFEx-repair 9.8%, SafeMoE 6.2%) while needing no reference routing weights. It holds under adaptive re-attack (7.1%) and input-only jailbreak (ASR 63.0%→18.2%), at a capability cost of 0.8 MMLU-Redux points and no over-refusal rise. The result transfers to Qwen3-30B-A3B (22.0%→3.9%).

Ablations (what each component buys)

  • A1 no entropy term: 4.6% → 8.9% — the anti-concentration term is what actually flattens the curve.
  • A2 redistribute all experts: 5.1% but MMLU 60.4→58.9 — targeting the safety-critical set keeps the tax low.
  • A3 no router regularization: 4.6% → 10.4% — without it the router drifts refusal back onto a small subset.
  • A4 SAFEx-repair instead: 9.8% — restoration does not remove the concentration; redistribution does.
