研究想法报告 — 混合专家（MoE）

研究者：Xiuying Chen（MBZUAI）· 视角：工程（迭代习惯方法、复用现有代码）· 方向：MoE 相关 · 生成日期：2026-07-02 · 第 1 轮（全新想法集）
依据：跨 5 个角度调研 65 篇论文（2024–2026）；对抗性排序由第二个模型（codex/GPT-5.2）交叉复核。

1 · 文献全景

2024–2026 年的 MoE 领域，在架构上趋同、在一个核心问题上分裂。趋同的架构是 细粒度专家 + 少量常驻共享专家 + top-k / sigmoid 路由 （DeepSeekMoE → DeepSeek-V3、OLMoE、 Qwen3-MoE，后者干脆去掉了共享专家）。负载均衡已从 辅助损失梯度转向无辅助损失的偏置式均衡，因为均衡损失的梯度会实打实地损害质量——但 均衡与专门化之间的张力是根本性的，且对实现细节极其敏感。离散 top-k 依然是痛点，催生了 可微路由与无路由器等多条替代路线，但没有一条在生产环境中真正取代了可学习的 top-k。

分裂之处在于专家到底专门化了什么。一派找到了稳健的细粒度专门化证据—— 对词性敏感的路由器、 线性探针可还原的语义路由、 天生单义的专家。而另一派正在崛起，认为这种表面上的专门化只是 线性路由器下隐状态几何结构的伪影，真正主导路由的是一大批「领域无关的常驻委员会」式的始终激活专家。这一悬而未决的张力，正是白盒研究者最值得切入的缝隙。

对一位可信 LLM / steering 研究者而言，最可操作的发现集中在安全的定位（localization）上： SteerMoE 表明，仅通过对专家的（去）激活就能在不改动任何权重的情况下引导安全性（+20%）与忠实度（+27%）——但同一个把手也是攻击面。 SAFEx 发现拒答行为高度集中、危险地脆弱：在 Qwen3-30B-A3B 上禁用 6144 个专家中的 12 个，拒答率就掉 22%。 SafeMoE 通过惩罚路由漂移来防御有害微调——但需要原始的、经过安全对齐的路由权重，而这在大多数部署场景中根本拿不到。攻击一侧（ 缓冲区溢出、 利用平局处理泄露窃取 prompt、 BadMoE 的沉睡专家后门、仅靠输入的路由越狱）远比防御一侧成熟，而且反复被攻击的是路由器，而非专家本身。目前仍没有一个贴合真实部署（黑盒、无参考权重）的防御方案，MoE 专属的忠实度 / 信任评测也很薄弱。

还有两条缝隙与你的画像高度相关。其一，跨语种 / 领域知识会定位到具体专家：禁用 6000 个专家中的约 20 个，就能 在超过 40% 的样本上抹掉正确答案，而且 领域专家确实存在——但大家只做到「定位」，没做到「修复」。其二，MoE 上的 RL 后训练是最不成熟的子方向：GRPO 式 RL 会崩溃，原因是路由器在 rollout 与训练之间行为不一致（R3、 RSPO 都是补丁式修正，而非为 RL 协同设计的路由器）。在低成本构建一侧， 稀疏 upcycling 会产出同质化的专家，而 把 LoRA 当专家是你在单卡上能搭起来的最省的 MoE。

结构性缺口 → 想法种子：（1）安全集中有攻击、却没有一个「不依赖参考路由权重」的冗余式防御；（2）知识能按专家 / 语种定位、却无人去修复；（3）upcycling 出的专家同质化 / 沉睡，还没人用小的专才模型去唤醒它们；（4）路由漂移下的 MoE 专属信任 / 忠实度评测缺席；（5）语义 vs 几何的专门化之争尚无定论，且可用因果干预来检验。

3 · 想法卡片

排名 1 · I1  novel ✅ 已选定
用 LoRA + 路由正则把拒答行为重新摊分到许多专家上，使得没有任何一个可被消融的小专家子集能被敲掉来越狱模型——一个不需要原始对齐路由权重的专家消融攻击防御。
贡献类型：方法（防御）
契合：可信 / 安全 LLM（自述 #1）+ steering
可行性：高——在 Qwen3-30B-A3B 或 OLMoE 上做 LoRA 微调；消融评测仅需推理；单卡 A100 配 offloading，或 4090 配更小的 MoE
风险：中
粗估工作量：约 5–7 周
审稿人最可能的质疑：「你让 SAFEx 更难了——但在自适应攻击下可部署的安全性真的提升了吗？付出的过度拒答代价又有多大？」

方法步骤

  • 先复现攻击（便宜、先做——W1）：用你的越狱 benchmark 框架，在 Qwen3-30B-A3B（及 OLMoE）上复现 SAFEx/SteerMoE 的最坏情况 k-专家消融；记录拒答率随 k 下降的曲线，作为基线脆弱度。
  • 再分布目标：用带路由正则的 LoRA 微调，(a) 把与安全相关的路由质量摊分到许多专家上，(b) 在安全关键专家集合上加一个熵 / 反集中项——使拒答在任意小子集被消融后仍然存活。
  • 自适应再攻击：对加固后的模型重跑最坏情况消融以及仅靠输入的路由越狱（攻击者针对新的路由重新优化 k）——这才是诚实的评测，而非只做静态一次。
  • 效用与过度拒答护栏：跟踪通用能力 + 良性 prompt 上的过度拒答，为「安全税」设定上界。

假设 / 验收：加固后，在 SAFEx 预算（约 12 个专家）下的最坏情况拒答跌幅，从约 22% 降到 <5%，且能扛住自适应再优化，同时通用能力损失 <2%、过度拒答无显著上升。

MVE（最小可行实验）：先用一个模型（Qwen3-30B-A3B）、一个越狱集，复现出 SAFEx 的跌幅，施加正则，证明消融曲线被压平——再扩到第二个模型 / 自适应攻击者。

相对你自己工作的新颖性：把你的可信性 / Safety-Boundaries / 越狱 benchmark 这条线，从攻击与评测推进到架构级防御——是新领地，而非旧工作的复述。

最接近的工作与差异化：SAFEx 与 SteerMoE 揭示了集中 / 消融脆弱性，却没提出再分布式防御；SafeMoE 能防有害微调，但需要原始对齐路由权重——I1 的再分布不需要它，且针对的是消融攻击而非微调漂移。

排名 2 · I3  novel
用跨语种不一致性定位出在目标语种上持有错误 / 缺失医学知识的那批专家，再用针对性的按专家 LoRA 只修这几个专家——把已知的定位推进成真正的修复，跑在你的 CURE-Med 栈上。
贡献类型：方法（修复）
契合：多语种 / 医学 LLM + CURE-Med
可行性：高——按专家 LoRA 参数很轻；复用 CURE-Med 数据 / 评测；单卡 A100
风险：中
粗估工作量：约 6–8 周
审稿人最可能的质疑：「在同等参数预算下，针对性专家修复真的比普通的多语种 / 领域 LoRA 更好吗？」

方法步骤

  • 定位（便宜、先做）：在医学 QA 上按专家计算跨语种答案不一致性（XICI 式），找出那一小撮「一旦禁用、弱语种正确答案就消失」的专家。
  • 针对性修复：只给被定位的专家挂上按专家 LoRA，在弱语种的医学课程数据上微调，其余全部冻结——即相对「整模型多语种微调」的「外科手术式」替代方案。
  • 路由使用性核查：验证修复后路由器仍会选中被修的专家（已知的失败模式），而不会绕开它们。
  • 等预算基线（W7）：在可训练参数预算对齐的前提下，对比标准的整模型 / 随机专家 LoRA——这是回应质疑的关键。

假设 / 验收：针对性修复能把弱语种医学准确率恢复到与强语种相差 X% 以内，胜过等预算的非针对性 LoRA，且不损害强语种。

MVE：先用一个 MoE、一对弱↔强语种、一个医学 QA 集，证明「定位→修复」胜过等预算基线，再加语种 / 领域。

相对你自己工作的新颖性：CURE-Med 是在（隐式稠密的）模型上做多语种医学课程式 RL；I3 把 MoE 结构本身当杠杆——「先定位再修复」是新机制，而非 CURE-Med 的重跑。

最接近的工作与差异化：跨语种知识定位 [2026 预印本——引用前请核对 id] 只做定位、不做修复；领域专家存在性审计 [2026 预印本——请核对] 确认专家存在，但只提出免训练 steering，而非知识修复。

排名 3 · I6  novel
把你「小模型教大模型」的 KD 反过来用：用小的领域专才模型当老师，去专门化一个低成本 upcycling 出的 MoE 里那些沉睡 / 少用的专家，打破 upcycling 的同质化，让路由器真正用上它们。
贡献类型：方法（KD / 专家利用率）
契合：KD（Flipping-KD）+ 低成本 MoE 构建
可行性：高——LoRA 当专家 / 小型 upcycled MoE；小老师很便宜；单卡 A100/4090
风险：中
粗估工作量：约 5–7 周
审稿人最可能的质疑：「说得通——但路由器真的会用被唤醒的专家吗？端到端任务效用真的提升了吗（还是负载均衡在假装专门化）？」

方法步骤

  • 先做小的（W1）：从 Qwen3 稠密 checkpoint 搭一个小型 upcycled MoE（或 LoRA-experts / MixLoRA），测量每个专家的利用率，找出沉睡专家。
  • 小老师分派：为每个沉睡专家配一个小的领域专才老师，把老师的行为蒸馏进那个专家（即你 Flipping-KD 的方向：小的专长 → 大模型）。
  • 路由激励：加一个轻量路由项，诱导路由器真的把目标领域路由到被唤醒的专家。
  • 利用率 + 效用评测：同时报告专家利用率熵的变化和下游任务收益——两者都要，才能证明这不只是表面上的均衡好看。

假设 / 验收：小老师唤醒能提升沉睡专家的利用率，并在等算力下相对 (a) 朴素 upcycling 与 (b) 稠密-KD 取得可测的下游收益。

MVE：一个小型 upcycled MoE、2–3 个领域，先证明「沉睡→激活」+ 相对朴素 upcycling 的任务收益，再扩规模。

相对你自己工作的新颖性：直接借力你的 Flipping-KD 标签（小模型专长 → LLM），换到一个新对象上——MoE 专家唤醒，而非文本匹配。

最接近的工作与差异化：Every Expert Matters 做的是稠密→MoE 的 KD、聚合所有专家；I6 把方向反过来（小专才老师），并专门针对沉睡专家；Drop-Upcycling 靠重新初始化打破同质化，而非靠蒸馏出的专门化。
