\section{Method}

\label{sec:method}

% PAPER_STUDIO_PARAGRAPH:M-P1

We investigate whether language models exhibit permutation invariance under random reorderings of answer options in multiple-choice question answering. Our approach compares model outputs across systematically shuffled option orders to determine whether predictions remain stable or shift with the presentation sequence. We operationalize the research problem through a controlled evaluation protocol that isolates the effect of option ordering while holding all other input characteristics constant. This overview establishes the experimental design used throughout the remainder of the section, defining the core procedure that subsequent paragraphs specify in detail.

% PAPER_STUDIO_PARAGRAPH:M-P2

For each item in the evaluation set, we obtain a base prediction by presenting the multiple-choice question with a reference option ordering. We then generate a set of permuted variants by applying distinct random permutations to the answer options, producing a candidate pool of reordered prompts. For each variant, the model's class score \(s_k(x)\) is recorded for every option \(k\), where \(x\) denotes the input prompt after permutation. We define permutation invariance as the consistency of the model's argmax choice across all orderings of the same question. The procedure fixes the prompt template, decoding configuration, and scoring function, while the tested variable is exclusively the option ordering.

% PAPER_STUDIO_PARAGRAPH:M-P3

We fix the number of random permutations applied to each question and the random seed used to generate them, ensuring that every item receives the same set of reorderings. The prompt template, including the question stem, option labels, and instruction phrasing, remains constant across all trials. The tested variable is exclusively the ordering of the answer options. We record the model's selected option and its associated class score for each permuted prompt, storing these outputs for downstream analysis. This design separates the fixed components of the evaluation from the manipulated variable, allowing any observed differences in predictions to be attributed to option ordering rather than to incidental variation in the input format.

% PAPER_STUDIO_PARAGRAPH:M-P4

We hypothesize that language models are not inherently invariant to option ordering, and that shuffled permutations can alter predictions in a systematic rather than random manner. One plausible mechanism is that the model attends disproportionately to option positions and surface cues, such as the label letter or the relative placement of the correct answer, rather than relying solely on semantic content. Under this account, the class score \(s_k(x)\) assigned to a given option may depend not only on its content but also on its position within the prompt, so that reordering changes the relative ranking of options even when the underlying question is unchanged. We treat this mechanism as a hypothesis to be tested rather than an established property of the models under study.
