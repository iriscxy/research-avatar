\section{Experiments}

\label{sec:experiments}

% PAPER_STUDIO_PARAGRAPH:E-P1

We will evaluate permutation invariance on multiple-choice question answering benchmarks. For each question, we will construct all possible option orderings via exhaustive permutation. The primary metric will be the fraction of questions where the predicted answer remains unchanged across all orderings; the secondary metric will measure the variance of class scores. Baselines will include a random-order strategy and a fixed canonical ordering. We will use greedy decoding with a fixed seed and will report results per dataset and model size.
